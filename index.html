About this tool
MolecuLens
An automated drug discovery research platform. Type any disease name — MolecuLens fetches real drug data from multiple databases, computes 135 graph-theoretic topological indices, trains 11 ML models with rigorous 5-fold CV, and delivers a full QSPR analysis with statistical significance testing, SHAP explanations, and drug-likeness filters.

Data sources

ChEMBL
Disease→drug mapping via MeSH headings. Returns ChEMBL IDs, canonical SMILES, and 7 RDKit base properties.
PubChem
20 physicochemical properties — XLogP3, ExactMass, TPSA, Complexity, FormalCharge, stereo counts and more.
ADMET (RDKit)
Fast, reliable ADMET predictions computed locally — GI absorption, BBB permeability, Caco2, Lipinski pass, QED.
UniChem + ChEMBL Bioactivity
Cross-database IDs (ChemSpider, ZINC, DrugBank, ChEBI) + experimental IC50, Ki, EC50, Kd values.

Documentation
How to use
MolecuLens runs a fully automated pipeline from disease name to publication-ready results.

Running the pipeline

1
Enter a disease name
Type any disease — diabetes, hypertension, alzheimer, cancer, asthma, epilepsy, parkinson, rheumatoid arthritis etc. Typos are handled automatically. The system validates against a curated MeSH disease list and probes ChEMBL for drug availability.
2
Wait for the pipeline to complete
The first run takes 20–45 minutes — fetching up to 200 drugs from 4 APIs, computing 135 topological indices per molecule, and training 11 ML models with 5-fold CV. The same disease searched again returns instantly from cache. On Railway free tier, the first page load may take ~30s to warm up — this is normal.
3
Explore results across 7 tabs
Drug Properties → Drug-likeness Filters → Topological Indices → Correlation Analysis → ML Performance → SHAP Importance → Data Preview.
4
Download your data
CSV (all drugs × all properties) and Excel (7 sheets) including full correlation matrices with p-values, VIF, and index definitions with formulas for citation.
