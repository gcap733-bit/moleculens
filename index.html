About this tool
MolecuLens
An automated drug discovery research platform. Type any disease name — MolecuLens fetches real drug data from multiple databases, computes 50 graph-theoretic topological indices, trains 11 ML models with rigorous 5-fold CV, and delivers a full QSPR analysis with statistical significance testing, SHAP explanations, and drug-likeness filters.

Data sources

ChEMBL
Role: Disease→drug mapping. The only free database linking disease names to drug molecules via MeSH headings.
Returns: ChEMBL IDs, canonical SMILES, and 7 RDKit-computed base properties (MolWt, LogP, TPSA, HBD, HBA, RotBonds, MolMR).
PubChem
Role: Physicochemical enrichment from standardised structures.
Returns: 20 properties — XLogP3, ExactMass, TPSA, Complexity, FormalCharge, HBD/HBA, RotatableBonds, HeavyAtomCount, AtomStereoCount, CovalentUnitCount, and more.
pkCSM
Role: ADMET pharmacokinetic prediction from SMILES.
Returns: Caco2, intestinal absorption, P-gp substrate, BBB permeability, CNS permeability, CYP substrates/inhibitors, hERG, AMES, LD50, hepatotoxicity. Falls back to RDKit-estimated ADMET if API is unavailable.
UniChem + ChEMBL Bioactivity
UniChem: Cross-database IDs — ChemSpider, ZINC, DrugBank, ChEBI, BindingDB (3 fallback strategies).
ChEMBL Bioactivity: Experimental IC50, Ki, EC50, Kd values from ChEMBL assays per drug.

Statistical analysis

Pearson correlation + p-values
Pearson r with two-tailed p-values for every index–property pair. Significance: *** p<0.001 · ** p<0.01 · * p<0.05 · ns.
Spearman correlation
Non-parametric rank-based correlation — detects monotonic non-linear relationships that Pearson misses.
VIF multicollinearity
Variance Inflation Factor for all 50 indices. VIF<5 = low, 5–10 = moderate, >10 = high (redundant index).
SHAP explanations
SHapley Additive exPlanations for the best model per property — shows exactly which index drives each prediction.
Documentation
How to use
MolecuLens runs a fully automated pipeline from disease name to publication-ready results.

Running the pipeline

1
Enter a disease name
Type any disease on the Pipeline tab — diabetes, hypertension, alzheimer, cancer, asthma, epilepsy, parkinson, rheumatoid arthritis, etc. Typos are handled automatically: "diabtes" suggests "diabetes". The system validates against a curated MeSH disease list and probes ChEMBL for drug availability before starting the pipeline.
2
Wait for the pipeline to complete
The first run of a disease takes 20–45 minutes — it fetches up to 100 real drugs from 4 APIs, computes 50 topological indices per molecule, and trains 11 ML models with 5-fold cross-validation. Do not close or refresh the browser tab. The same disease searched again returns instantly (<1 second) from the results cache.
3
Explore results across 7 tabs
Results are displayed in 7 tabs: Drug Properties → Drug-likeness Filters → Topological Indices → Correlation Analysis → ML Performance → SHAP Importance → Data Preview.
4
Download your data
Two download buttons appear: CSV (all drugs × all properties) and Excel (7 sheets) — Drug Data, ML Results, Best Models, SHAP Importance, Correlation (Pearson + Spearman + VIF), and Index Definitions with full formulas ready for citation.

Understanding the results

R² (coefficient of determination)
How well topological indices predict the property. R²=1 is perfect, R²=0 is no better than random. Values above 0.7 are considered strong for QSPR research.
MAE (mean absolute error)
Average prediction error in the property's own units. Lower is better. Compare MAE only across models for the same property, not across different properties.
SHAP values
Mean absolute SHAP value per topological index. Higher = that index contributes more to the prediction. Use to identify which structural features matter most.
Pearson r + p-values
*** = highly significant (p<0.001). A high |r| with low p-value means the relationship is both strong and statistically reliable.
VIF multicollinearity
VIF <5: indices are independent. 5–10: moderate overlap. >10: two indices carry essentially the same structural information.
Drug-likeness filters
Lipinski pass = likely good oral bioavailability. Veber pass = additional oral absorption constraint. PAINS pass = no problematic substructures.

Tips and notes

🔄 Repeat searches are instant — results are cached after the first run.
⏳ Do not close the tab while running. The job runs on the server, but the browser polls for completion every 5 seconds.
📊 More drugs = better ML — diseases with many ChEMBL entries give more statistically reliable QSPR results.
🧬 Sparse bioactivity — BIO_IC50, BIO_Ki etc. are often null. ChEMBL only has experimental data for a fraction of drugs per disease. This is normal.
📥 Excel workbook is publication-ready — the Correlation sheet has colour-coded heatmaps and the Index Definitions sheet has all formulas for direct citation.
🔬 ADMET fallback — if pkCSM is unavailable, RDKit-estimated ADMET properties are computed locally (marked ADMET_Source = RDKit_fallback).
🌓 Theme toggle — switch between dark and light mode using the button in the top-right navigation bar.
